# Лабораторна робота № 5. Робота з рядками

**Варіант 5.** Тема: «Текст посилання» + підвищена складність № 5.

## Мета

Навчитися працювати з рядками: зрізи, перевірка символів, пошук, розбиття.

## Завдання

1. Перевірити, чи починається рядок із `https://` (без урахування регістру) і чи далі є текст без пробільних символів. Вивести `Так`/`Ні`.
2. Зі спрощеного рядка `https://HOST/PATH` (без пробілів) виділити HOST до першого `/`. Шлях може бути відсутнім; порожній HOST — помилка.
3. **Підвищена складність № 5.** Вивести індекси всіх збігів сигнатури (навіть тих, що перекриваються) та їх кількість; регістр враховується; порожня сигнатура — помилка; якщо збігів немає — `Не знайдено` і `0`.

## Теорія

* Рядок у Python незмінний; зріз `text[:8]` бере перші 8 символів, `lower()` повертає рядок малими літерами.
* `ch.isspace()` перевіряє пробільний символ (пробіл, табуляція, перенесення рядка тощо). Введений рядок **не обрізається**, тому пробіл на початку — це порушення формату.
* `url.split("/")[0]` дає частину до першого `/`.
* Пошук усіх збігів: `text.find(signature, pos + 1)` у циклі. Крок `+1` (а не довжина сигнатури) дозволяє знаходити збіги, що перекриваються (`ABA` у `ABABABA` — позиції 0, 2, 4).
* Це лише перевірка формату рядка: вона нічого не говорить про існування чи безпечність адреси.

## Запуск

Потрібен Python 3.10+ (перевірка: `python --version`). Сторонні бібліотеки не потрібні.

```bash
python main.py
```
